## 禁区 1 · 模型词域名站 ⚠ **v3 订正(2026-08-27 当日,用户挑战后复核)**

光 Nano Banana 就 **6 个域名**(`nanobanana.im` / `nanobnana.com` / `nano-banana2.co/.com/.org` /
`nanobananapro.org`);另有 `seedance2.so` / `www-veo3.com` / `sora2ai.io` / `kling3.io` /
`zimageturbo.com` / `wan2-7.io` / `longcatai.net` / `gptimage2ai.com` / `whisper-ai.org`。

**生意**:抢注模型名域名 → 包装该模型的在线调用 → 吃发布期搜索洪峰。
**成本**:域名几十美元 + 开发 3–5 天。**现金极低,这正是诱惑。**

**拆开看(哥伦布 `nano banana` 全量 34 站,2026-05→07)**:

| 类型 | 样本 | 走势 |

# 第三部分:三条横向警告

## 1. 干净的词也会崩 —— `pixelartvillage.com`

头部词全干净(`image to pixel art` 11,940 / **CPC $1.61–2.26**,库里最高档之一),AdSense,DR 8。
流量:**2025-08 的 2,254,727 → 2026-07 的 254,352,跌 89%。**

**选对词、词也值钱、照样一年跌九成。工具站流量是脉冲式的,不是复利资产**——
与[准公理 A](../axioms.md)直接冲突,选形态时必须计入。
**这也是形态 D(品牌驱动)相对工具站的结构性优势:direct 36–40% 不受算法更新影响。**

## 2. 容易排 = 不值钱,是同一件事的两面

音频类 40 个站里 **DR ≤6 的有 14 个,合计约 147 万月访问**。但同批 CPC 全在 **$0.15–0.58**,
`voiceenhancer.ai` **零变现检测**,`whisper-ai.org` 哥伦布描述直接写「靠 AdSense 变现」,
地理集中在 India 22% / Pakistan / Indonesia / Turkey。

**CPC 低 → 没人愿意投入 → DR 0 才排得上去。**

## 3. 42 个站里,`payment_providers` 非空的只有 1 个

只有 `myimageupscaler.com`(Stripe)。即使计入 [teardown 只扫首页的假阴性](../sources/columbus.md),
仍说明:**这个库的主流变现是广告与未变现,不是订阅。**
而定价线索可读的少数几个是:`thefacereport` **$17.49 一次性**、`fontvibe` **$3.99–24.99/月**、
`datephotos` **$29–800**、`coprep` **$12–72/月**、`hinoter` **$2 / $600**、`ai3dgen` **$3**。

# 第四部分:结论

## 按现金成本排序的可执行清单

| 优先级 | 形态 | 样本 | 现金 | 时间 | 关键理由 |
|---|---|---|---|---|---|
| **1** | **通用需求词 + 一次性付费** | `thefacereport.com` | **< $50** | 2–3 周 | 四层全过,DR 0 / 零外链 / 零投放 / 4 个月 31.8 万 / US 51% / **$17.49 一次性** |
| **2** | **开源生态配套工具** | `mermaideditor.io` | **< $30** | 1–2 周 | 推理 $0、外链 $0、技能栈重叠最高 |
| **3** | **programmatic 小长尾** | `fontvibe.ai` | **< $50** | 2 周 | 小头部词也能起量,有完整订阅阶梯 |
| **4** | **社媒驱动品牌** | `jobsuit.ai` | **≈ $0 现金** | 持续 | **解「零分发面」死结的唯一样本**;成本是内容产能不是钱 |

## 立刻可做、不需要新站的一件事

**给 partfit3d 铺 programmatic 长尾页。** `fontvibe.ai` 用 3,380 月搜的头部词做到 10.7 万访问,
靠的是无数 200–500 月搜的长尾。partfit3d 的 `split 3mf` 约 1,180 曝光/月一直被当作"词太小"
——**这个前提可能是错的**。

## 仍未解决的前置问题

**08-12 定的 $2–5K/站外链预算是真能花的钱吗?** 至今 15 天未花一分。

若这笔钱是纸上的,应当撤回 08-12 框架,避免它继续影响筛选口径。
