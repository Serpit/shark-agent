# X 冷启动与放大 SOP

> **定位**:个人 IP 实验的运营层 SOP,解决"账号如何起第一波信任和曝光"。写单条推文仍用 [x-tweet-writing-templates.md](x-tweet-writing-templates.md);本文件解决发布前后的关系、互动、转化与监控。
>
> **来源**:[2026-05-x-ai-media-cold-start.md](../findings/2026-05-x-ai-media-cold-start.md)。

## 底层原则

X 的核心不是单条内容爆不爆,而是持续公开展示判断力,进入同频人的关系网络,并把信任沉淀成长期资产。

当前账号不要做泛 AI 自媒体,而是围绕三条内容支柱:

- 独立开发出海
- 海外 App / 订阅商业化拆解
- AI 提效与创业验证

## 冷启动三步

### Step 1 · 补齐账号基础

- 开通基础 Premium 即可,先不追 Premium+
- 主页一句话定位:技术开发者的海外创业探索记录
- Bio 放清楚:正在做什么、持续分享什么、你希望吸引谁
- 主页链接优先放长期阵地或项目页;没有项目页时先放 X 置顶自我介绍

### Step 2 · 写一条"秀肌肉 / 立人设"置顶推文

必须回答三件事:

1. 我是谁:海外 App 开发背景 / 技术人 / 正在做出海探索
2. 我凭什么值得关注:真实工作经验、正在公开跑 SEO 站 / 独立开发实验、会复盘失败和判断
3. 关注我能持续获得什么:独立开发出海记录、海外产品商业化拆解、AI 提效与创业验证

没有夸张战绩时,不要假装大佬。用"养成系 IP"路线:真实记录每一次方向推翻、选词 NO-GO、上线、复盘。

### Step 3 · 借已有圈子破第一波曝光

优先级:

1. 长期在 10-20 个同领域大 V 评论区做高质量回复
2. 引用评论大 V 的高热推文,补自己的真实判断或反例
3. 有内容资产后,再私信请求同频大 V / 社群朋友转推
4. 可选择小型付费社群,但只作为关系入口,不是增长捷径

## 每日 30 分钟互动节奏

- 10 分钟:扫监控列表,找 3 条与三支柱相关的推文
- 10 分钟:对 1 条做引用评论,加自己的判断
- 10 分钟:对 3-5 条做高质量评论,目标是"被原作者记住",不是刷存在感

高质量评论标准:

- 补一个具体案例
- 给一个反例
- 把原推观点拆成可执行步骤
- 连接到自己的实验数据或观察

## 信息监控系统

监控对象分三类:

- AI / Coding Agent:OpenAI、Anthropic、Claude Code、Codex、Cursor、MCP、agentic workflow
- 独立开发与出海:yidabuilds、iamsveachen、ai_xiaomu、哥飞等
- 中文 AI / 技术圈关键节点:op7418、dotey、imxiaohu、宝玉等

日报只做两件事:

1. 找可参与讨论的热点
2. 找可沉淀为自己内容的真实问题

不要为了追热点稀释账号定位。泛 AI 新闻只在能连接到"开发者出海 / 创业验证 / 产品商业化"时才发。

## 变现理解顺序

对当前阶段,优先级是:

1. 同频连接和需求线索
2. 后端产品 / 服务 / 内容资产转化
3. CPS / 商单 / 社群 / 咨询
4. X 创作者分成

X 创作者分成只当附加正反馈。当前官方门槛包含 Premium、近 3 个月 500 万 organic impressions、500 verified followers、Stripe 和身份验证;中国大陆个人支付链路不应默认可闭环。

## 每周复盘

记录四个数:

- 本周发了几条原创 / 引用评论 / 高质量评论
- 新增了几个同频互动对象
- 是否产生需求线索 / 私信 / 被引用
- 哪类内容让别人记住你

若一周只在看热点、没有输出个人判断,说明已经偏离个人 IP 主线。
