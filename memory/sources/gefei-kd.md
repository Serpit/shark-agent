# 数据源:哥飞版关键词难度 MCP(gefei-kd)

> **定位**:给一个英文词,直接返回 **0-100 难度分 + 进入前十的链接预算 + 前十竞争盘面明细**。
> 它顶替的是原本要靠 `seo-advisor` 一问一答才能拿到的两样东西(KD 第二口径、外链预算数字),
> 从**对话式问答**变成**结构化调用**——同样的信息,不消耗积分、不受它答不答得全的影响。
>
> **不是**通用关键词工具:**不给搜索量、不给 CPC、不给词族**。那三样仍归 `seo-competitor`(Semrush)。

## 接入方式

MCP server,**已配置**(2026-08-13):

| 项 | 值 |
|---|---|
| 名称 | `gefei-kd` |
| transport | HTTP(streamable) |
| endpoint | `https://seo.web.cafe/kd/mcp?token=<token>` |
| scope | **local** —— 存 `~/.claude.json` 本项目段 |
| serverInfo | `keyword-difficulty-gefei` v4.11 |

> **token 在 URL 里,因此配置绝不入库**(仓库纪律:凭证一律存仓库外)。
> 换机器要重配:`claude mcp add --scope local --transport http gefei-kd '<带 token 的完整 URL>'`。
> 新增/改动后**必须重开会话**,MCP 工具只在会话启动时加载。

## 唯一的工具

`estimate_keyword_difficulty`

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `keyword` | ✅ | — | **英文词**,如 `ai photo editor` |
| `gl` | | `us` | Google 国家码,可 `gb`/`ca`/`au`/`de`/`jp`/`sg` |
| `hl` | | `en` | 语言码 |
| `force` | | `false` | 跳过结论缓存强制重算 |

返回一整篇 Markdown 报告,四段:**难度分 → 判断原因 → 前十竞争盘面表 → 模型口径说明**。

## 输出字段与读法

以 `csv to qbo`(US,2026-08-13 实测)为样本:

| 字段 | 样本值 | 怎么读 |
|---|---|---|
| **难度分** | 27.6 / 100(容易·**品牌词口径**) | ← 真正有行动意义的那个数 |
| **常规口径对照** | 28.4 / 100 | 品牌词时它自己标注"**无行动意义**",别拿来做判断 |
| **链接预算** | 25–50 个引用域(中值 35);目录型为主时 80–200 | 进入前十所需,**插值出来的,不是数出来的**(见陷阱 2) |
| **对应 DR 量级** | 约 DR 23 | 打这个词的站大致要到的权重 |
| **计算时间** | 带 `(缓存结果)` 标记 | 想要当日数据必须 `force: true` |

**前十竞争盘面表**每行给:域名 / 页面类型(首页·内页) / DR / 月流量 / 域名年龄 / **专门经营**(标题是否命中该词) / **体验分**(停留·跳出·页均) / 站点强度 / 难度贡献。

这张表比分数本身更有用——它直接回答 Step 5a 要人肉去 Semrush 查的问题:**盘面里最弱的那个站长什么样**。
样本里 `accountingconverter.com` DR 5 / 域名 6 个月 / 月流量 1674 就排到第 5 位,这一行的信息量顶一次 Domain Overview。

模型口径(它自己写在报告末尾):站点强度 = 0.6×DR + 0.4×流量分(对数归一化);
内页折 45%、标题命中的专门经营页折 65%、首页全额;链接预算按 **Ahrefs 官方 KD→引用域曲线**由难度分插值。

## 信任等级

**第三方估算**,与 Semrush / SimilarWeb / 哥伦布同层。落盘必须标「gefei-kd + 拉取日期」,与 GSC 冲突时**一律以 GSC 为准**。

注意它内部混着两类东西,不要一视同仁:

| 类型 | 字段 | 说明 |
|---|---|---|
| **估算值** | 难度分、DR、月流量、体验分、链接预算 | 第三方估算,只取排序不取绝对值 |
| **结构化事实** | 前十的域名、页面类型、域名年龄、标题是否命中 | 抓 SERP 得到的观察,可直接参考 |

## ⚠️ 已知陷阱

### 1. 品牌词会自动切口径,读数前先确认是哪一个

命中品牌/导航词时,主分数变成「**第三方以衍生内容(alternative / review / vs / 教程)进入的难度**」,
不再是"排这个词的难度"。两个口径的数字可能很接近(样本 27.6 vs 28.4),**不看标注就会读错含义**。
判定依据是它看到前十平台型结果密集(reddit / youtube),会在「判断原因」里明说。

### 2. 链接预算是曲线插值,**不能替代查竞品实际引用域**

它的 25–50 个引用域是**从难度分沿 Ahrefs 曲线插出来的**,不是去数前十各站真实有多少引用域。
和 [`keyword-hunt`](../../.claude/skills/keyword-hunt/SKILL.md) Step 5a 要的「竞品实际引用域」是两个不同的量,互不替代:

- **它给的** = 这个难度分的词、统计上大约要多少域 → 桌面粗估、排预算量级
- **Step 5a 要的** = 具体那个最弱竞品实际拿到了多少域 → 判"打不打得动"

另外 2026-08-12 已记结论:**Semrush 引用域实测低估达 16 倍,判据要用 Ahrefs 页面级数**(见 [`risks.md`](../risks.md))。
这条对本工具同样适用——它的预算数只是量级参考,**GO/NO-GO 不能只凭它**。

### 3. 它不给搜索量、不给 CPC

所以它**不能单独完成 Step 3 的四维筛**。量与 CPC 仍走 Semrush;Semrush 到期后只剩哥伦布关键词榜和 `seo-advisor` 问答两个量的来源。

### 4. 只支持英文词 + Google

中文词、Bing、其他搜索引擎均不在范围内。

### 5. 默认吃缓存

报告会标 `(缓存结果)` 和计算时间。样本拉于 2026-08-13,返回的却是 08-12 的计算结果。
**要判断"最近有没有人杀进来"必须 `force: true`**,否则拿到的是几天前的盘面。

## 与其他数据源的分工

| 问题 | 用谁 |
|---|---|
| 这个词多难打 / 要多少外链 | **gefei-kd** |
| 前十最弱的那个站长什么样 | **gefei-kd** 竞争盘面表(省掉一次 Domain Overview) |
| 这个词多大 / CPC 多少 / 词族有哪些 | Semrush([`seo-competitor`](../../.claude/skills/seo-competitor/SKILL.md)) |
| 这个词在涨还是在跌 | Google Trends |
| 这个词已经被哪些 AI 站占了、谁在涨谁在死 | [哥伦布](columbus.md) `/ai-keyword-rank` |
| 竞品实际引用域(判可打性) | Ahrefs —— **不要用 Semrush,也不要用本工具的插值** |
| 为什么会这样 / 该怎么打 | [`seo-advisor`](../../.claude/skills/seo-advisor/SKILL.md) —— 他人观点,须过公理扫描 |
| 我自己的站表现如何 | GSC([`seo-data`](../../.claude/skills/seo-data/SKILL.md))—— **唯一真值** |

## 使用前提

同 [哥伦布](columbus.md):**拉数前先答一句「这次查询的结果会落到哪个具体动作」**。
本工具调用成本极低(无积分、秒级返回),正因为便宜,**更容易变成"再查几个词看看"的公理 6 陷阱**。
每次调用应当绑定到一个待定标的词,而不是批量刷候选池。
